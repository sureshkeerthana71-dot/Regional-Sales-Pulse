Regional Sales Pulse
Project Description

This project analyzes sales data to understand sales, profit, and business performance.

Technologies Used

Python
Pandas
Streamlit
Plotly

Features

Total sales and profit calculation
Profit margin calculation
Monthly sales chart
Product profit analysis
Regional sales analysis

How to Run

Install the required libraries: pip install -r requirements.txt
Run the application: streamlit run app.py
Open the application in your browser.

Conclusion

This project helps businesses understand sales performance and improve profitability.
